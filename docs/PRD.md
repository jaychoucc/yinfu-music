# 双端音乐应用 PRD — 音符 Note

> 任务编号：software-musicdl-dual
> 作者：产品经理 许清楚
> 基准：开源项目 [CharlesPikachu/musicdl](https://github.com/CharlesPikachu/musicdl) + 参考实现 `app.py`（Flask 后端 + SSE 流式搜索代理）

---

## 1. 产品目标

1. **跨端一站式音乐体验**：用户在一个搜索框下，跨咪咕 / 网易云 / 酷我 / QQ 四个音源聚合搜索与播放，不必安装多个客户端。
2. **极致流式响应**：从输入关键词到首条结果可见 ≤ 3 秒（典型场景），单源卡死不阻塞整体结果区（参考 `app.py` 的 SSE + 看门狗机制）。
3. **学习与可控性优先**：以开源数据源为基础，提供播放、歌词、下载、播放队列四件套，所有下载文件本地可访问、无加密。

> 范围外（本期不做）：注册登录、云端歌单同步、付费内容、桌面端、移动端 iOS、社交分享。

## 2. 目标用户

- 国内音乐爱好者，习惯多平台切换找歌；不愿为单个平台开会员。
- 开发者 / 自托管用户，希望本地跑一个不依赖账号体系的音乐服务。
- 高校学生 / 通勤族，需要桌面 + 手机都能用同一套搜索结果。

## 3. 用户故事

### 3.1 网页端（Flask + 静态前端）

1. **作为用户**，我想在搜索框输入"周杰伦"并选择"咪咕"标签，**以便**只看咪咕来源的结果而不被其他音源干扰。
2. **作为用户**，我希望搜索结果一条一条"流"出来（不必等所有源都返回完），**以便**前几条可立即点击试听。
3. **作为用户**，我点击列表中的某首歌后，**希望**播放控制条立即加载并自动播放，且右侧歌词面板同步滚动到当前行。
4. **作为用户**，我点击下载按钮后，**希望**看到进度条 / 速度 / 完成后浏览器提示保存，且文件名包含「歌名 - 歌手」。
5. **作为用户**，我可以把若干首歌加入"播放队列"，**以便**按顺序自动连播并跳过失败项。

### 3.2 安卓端（Kotlin 原生）

1. **作为用户**，打开应用进入"首页"看到推荐歌单瀑布流，**以便**无需输入关键词也能发现歌曲。
2. **作为用户**，在底部 Tab 切到"搜索"输入关键词，**可以**从顶部芯片切换音源并查看实时流入的结果列表。
3. **作为用户**，点击一首歌进入沉浸式播放页（全屏封面 / 旋转封面 / 大字号歌名），**可以**通过通知栏控制上一首 / 暂停 / 下一首。
4. **作为用户**，歌词页支持长按复制当前行，且当前行高亮、上一行次高亮。
5. **作为用户**，下载完成后文件保存到本地 `Music/Soundtrack/`，**以便**系统播放器或其他 App 也能播放。

## 5. UI 设计要求

### 5.1 网页端（音符 Note 暗色主题，参考 `screenshot.png`）

- **整体配色**：背景 `#0f1115` 系深黑；强调色暖橙（播放按钮 / 进度条 / 波形），次强调粉色（当前播放行渐变描边）；文本主色白、次色灰。
- **顶栏**：
  - 左：等高条 Logo（5 根高低不同的彩色矩形，象征均衡器 / 频谱）+ 「音符」+ 副标「Note · powered by musicdl」。
  - 右：圆角搜索框（占位"搜索歌曲 / 歌手"），回车触发。
- **音源 Tab**：横向胶囊样式，选中态描边 + 文字加亮；默认仅启用咪咕（与 `app.py` 默认值一致），可点选其他。
- **结果列表**：表头「曲目 / 专辑 / 时长」三列；每行：左侧 48×48 圆角封面 → 歌名（白）+ 歌手（灰）→ 专辑（灰）→ 时长（右对齐）。
  - **当前播放行**：左侧 4px 粉→橙渐变描边 + 内部轻微提亮；右侧"词"徽标。
- **播放控制条（底栏）**：
  - 左：当前曲信息 + "词"按钮。
  - 中：进度条（已播放区橙色），下方 `0:00 / 3:00`。
  - 中右：大号橙圆播放 / 暂停按钮 + 上一首 / 下一首。
  - 右：橙色频谱柱（按当前播放音量实时跳动，可静态占位降级）+ 音量滑块。
- **歌词面板（右抽屉）**：可关闭；当前行 100% 不透明 + 缩放 1.05；其它行 35% 透明灰；行间留白宽松。

### 5.2 安卓端（网易云音乐 / QQ 音乐风格）

- **首页**：
  - 顶部轮播 Banner（圆角 16dp）。
  - 「推荐歌单」标题 + 副标题"每日更新"。
  - 双列瀑布流卡片：圆角 12dp 封面 + 标题（粗体 16sp 黑色 / 白色）+ 副标题（12sp 灰），点击进入歌单详情。
  - 整体品牌色用歌曲封面主色提取的渐变（用 Palette 库或自实现简单版）。
- **搜索页**：
  - 顶部音源水平 Chips（单选，选中态实心品牌色）。
  - 搜索框：圆角 24dp 灰底；输入时实时去抖请求。
  - 结果列表：每条 56dp 高，左封面 48×48 圆角 8dp，右歌名 + 歌手，最右显示音源小标签；点击进入播放页。
- **沉浸式播放页**：
  - 背景：用当前歌曲封面做高斯模糊 + 暗化（70%）作底。
  - 中央：240×240 旋转封面（播放时匀速旋转，暂停停止）。
  - 下方：歌名（22sp 粗体白）+ 歌手（14sp 灰白）。
  - 进度条：自定义细线，拇指为品牌色实心圆。
  - 控件行：♡ 收藏 / 上一首 / 大号播放按钮（68dp 圆形，品牌色实心）/ 下一首 / ⤓ 下载。
  - 底部切到「歌词」Tab：当前行白色 18sp 高亮、上一行 14sp 半透明、其它 12sp 更暗；支持长按复制。
- **我的**：本地下载（按时间倒序）/ 播放历史 / 清除缓存。
- **底部 Tab**：图标 + 中文标签，3 个 Tab 等宽，选中态品牌色（默认红橙渐变，可让用户在设置里改）。

## 6. 非功能需求

| 类别 | 指标 |
|---|---|
| **性能（网页端）** | 首字节 ≤ 500ms；SSE 首条结果 ≤ 3s（咪咕正常情况下）；音频首帧 ≤ 1s（命中已解析音源后）。 |
| **性能（安卓端）** | 冷启动 ≤ 2s；列表滚动 60fps；播放页切换 ≤ 300ms。 |
| **超时兜底** | 单源搜索 35 秒强制结束；音频代理连接 10s + 读取 30s 超时；下载 30s 无数据流则中止并提示。 |
| **错误提示** | 1) 任一源超时 → 该源显示"无响应"，其它源继续；2) token 失效（重启后）→ 列表内标记"已过期，请重新搜索"；3) 音频 404 → 自动切下一首并 Toast；4) 下载失败 → 保留 `.part` 并允许断点续传。 |
| **可观测性** | 后端日志含 keyword、source、resolved_count、duration；安卓端崩溃接入 Logcat + 本地 `crash.log`（不上传第三方）。 |
| **安全** | 仅监听 127.0.0.1；CORS 默认同源；下载目录在用户主目录下。 |
| **可移植** | 网页端 `pip install musicdl flask requests` 可跑；安卓端 AGP 8.2 + Kotlin 1.9，依赖最小化（OkHttp、Glide、ExoPlayer-Media3、Coroutines、Palette 任选其一）。 |
| **构建约束（安卓）** | 本机无 Android Studio；构建链 JDK17 + Gradle 8.7 + cmdline-tools（腾讯/清华镜像）。Gradle 必须配置 `mavenCentral` 镜像 + `google()` 镜像；首次构建允许 10-15 分钟依赖下载。 |
| **网络约束** | 目标用户在国内；网页端所有外部 HTTP 由 Flask 代理；安卓端直连（需在 `network_security_config.xml` 允许 HTTP 明文到这 4 个域名）。 |
| **免责声明** | 仅供个人技术学习，勿用于商业用途；音源版权归各平台所有。 |

## 7. 待确认问题（附默认假设，不阻塞开发）

| # | 问题 | 默认假设 |
|---|---|---|
| Q1 | 默认音源启用哪几个？ | 沿用 `app.py` 的设置：仅咪咕默认开，其他音源在 UI 上一键开启。 |
| Q2 | 是否需要登录 / Cookie 池？ | 不需要，全部走公开搜索接口；遇到 403 / VIP 资源显示"该平台暂不可用"且不下载。 |
| Q3 | 音频格式是否限制只 mp3？ | 全部按音源实际返回（mp3 / flac / m4a 等），前端用 `<audio>` 自动解码。 |
| Q4 | 歌词来源？ | 沿用 musicdl 的 lyric 字段；缺失时歌词面板显示"暂无歌词"。 |
| Q5 | 安卓端最低 SDK？ | minSdk 24（覆盖率 >97%），targetSdk 34。 |
| Q6 | 安卓端是否上 Media3 / ExoPlayer？ | 走 Media3 ExoPlayer（官方推荐，体积可控）。 |
| Q7 | 是否需要播放队列持久化（安卓）？ | 进程内 + DataStore 落地最近一次队列，重启恢复。 |
| Q8 | 下载目录路径？ | 安卓：`MediaStore.Audio.Music` "Soundtrack" 专辑（系统级相册/音乐可识别）；网页：`./downloads/<source>/`。 |
| Q9 | iOS / 桌面端是否纳入？ | 本期不纳入。 |
| Q10 | 商业化 / 会员内容？ | 不做，遇到 VIP 资源按"无音源"处理。 |

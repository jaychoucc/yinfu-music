# 声轨 Soundtrack —— 网页端

基于 [musicdl](https://github.com/CharlesPikachu/musicdl) 的聚合音乐搜索/播放/下载网页。

## 启动方法

确保已安装 `flask`、`requests`、`musicdl`，然后执行：

```bash
python server.py
```

服务将运行在 `http://127.0.0.1:58652`。

Windows 环境也可直接双击 `run.bat`。

## 功能

- 顶部音源胶囊：咪咕 / 网易云 / 酷我 / QQ，可多选
- SSE 流式搜索，单源 35 秒超时兜底
- 底部播放条：播放/暂停/上下首/进度条/音量/频谱动画
- 右侧歌词抽屉：当前行高亮、自动滚动、点击跳转
- 播放队列基于当前搜索结果，支持双击切歌
- 键盘快捷键：空格 播放/暂停，← → 切歌，↑ ↓ 调音量
